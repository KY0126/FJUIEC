# 永信旅人小鎮

以 [a16z AI Town](https://github.com/a16z-infra/ai-town)（MIT 授權）改作的顧問練習場，配合永信旅遊提案：客人說「都可以」的時候，練習改問「怎麼旅行」。語言模型用免費的 Ollama（qwen2.5、mxbai-embed-large），後端用 Convex 本機部署，全部在自己的電腦上執行。

## 玩法

- **顧問練習**：扮演新進顧問林家瑋，找客人聊天。聊完的回饋卡會顯示信任變化、問到的面向（節奏、取向、預算、旅伴、避雷），問到 3 個以上就解鎖客人的旅人角色。
- **客人體驗**：扮演林雅婷，讓資深顧問王美玲用新流程引導你；回饋卡顯示美玲問到你哪些面向。
- **事件投放**：門口邀請做測驗、歐洲旅遊講座、新人第一次接待；LINE 分眾推播（回溯點亮地圖）和一般促銷訊息的對照。
- 和客人聊天時，右側會出現「客戶資料卡」，從客人說的話自動整理。

所有判斷都用關鍵字，聊完只呼叫一次模型（給信任分數與理由）。AI 客人的反應是模擬，不代表真實成效。

## 在筆電上執行

1. 需要先安裝 Node.js 與 Ollama。
2. 到 GitHub 的 `KY0126/FJUIEC` 下載 ZIP，把裡面的 `town` 資料夾複製到 `文件\ys-town`。
3. 如果電腦上還有其他用 Convex 本機部署的專案在執行，先把它的黑色視窗關掉（會搶同一個連接埠）。
4. 雙擊 `啟動永信小鎮.bat`（第一次會自動下載模型、安裝套件）；Convex 問登入時選 Start without an account。
5. 黑色視窗開著時雙擊 `立即重設.bat`，再按 F5。
6. 對話太慢時，雙擊 `加速設定.bat`；仍慢就雙擊 `切換小模型.bat`。
