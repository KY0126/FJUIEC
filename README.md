# FJUIEC｜輔大《創新創業社》

## 歐洲旅人護照｜旅行風格測驗（課程原型）

輔大創新創業社「永信旅遊」課程專案的可操作原型：12 題情境測驗，依「節奏 × 取向」分出五種旅人角色（白兔／紅心皇后／柴郡貓／瘋帽匠／愛麗絲），並提供示意推薦行程、歐洲探索地圖與旅人護照足跡頁。

- 線上體驗：https://ky0126.github.io/FJUIEC/
- App 版原型（旅客端，接 Supabase）：https://ky0126.github.io/FJUIEC/app/　說明見下方「App 版原型」
- 手機網頁，不用下載：iPhone 用 Safari 開啟後按「分享 → 加入主畫面」，Android 用 Chrome 開啟後按「安裝應用程式」或「加到主畫面」，之後就像 App 一樣從桌面圖示全螢幕開啟。
- **目前為展示版，不收集任何作答數據**；不需登入。推薦行程皆為課程示意，價格參考永信官網同區域公開標價（2026/10/17 查詢）。
- 本頁不是任何旅行社的官方網站。

## 使用流程

1. **開場動畫**：白兔跑過、掉進兔子洞、抵達歐洲（可略過，同一次瀏覽只播一次）。
2. **封面**：五種旅人角色預覽，12 題、約 1 分鐘。
3. **12 題測驗**：每題上方一張情境插畫，點選答案自動進下一題；Q12 可複選。
4. **結果頁**：
   - 角色卡：五種角色分數全保留，可「換個角色」、可分享、可隱藏頭像。
   - 推薦行程：依節奏、主題、預算與避雷項目排序，並寫出推薦原因。
   - 行程標籤：每張推薦卡標示每日步行量、最長單趟車程、室內比例、有無購物站，以及建議出發月份與當地均溫（皆為示意數字）。
   - 篩選條件：自由時間多、連泊不換飯店、同節奏的人同團、10 天內、預算以內、少拉車、無購物站、走路不累、避開炎熱。
   - 傳給旅伴：一鍵把 3 團推薦和測驗連結傳給同行的人，對方也能做測驗、比對角色。
   - 歐洲探索地圖：真實國界，對應永信官網 23 個歐洲分類；北歐藍、西歐淺橘、東歐米褐、南歐淺黃，深灰是不在永信歐洲線的國家，深藍色是目前選取。
5. **旅人護照足跡頁**：以示意資料呈現等級禮遇、出團後的足跡地圖與郵戳紀錄。護照只做數位版（網頁與 LINE），不印實體，用於行銷與 CRM。
6. **回饋**（收集數據時才顯示）：推薦符合度（1–5 分）、5 題補充問卷、選填訪談邀請。

## 五種旅人角色

| 角色 | 代表 | 節奏 | 取向 |
|---|---|---|---|
| 經典收藏家 | 白兔 | 精準 | 經典名景 |
| 嚴選鑑賞家 | 紅心皇后 | 精準 | 深度體驗 |
| 慢遊生活家 | 柴郡貓 | 留白 | 深度體驗 |
| 隨興巡禮者 | 瘋帽匠 | 留白 | 經典名景 |
| 從容探索家 | 愛麗絲 | 均衡 | 不分取向 |

頭像為原創維多利亞剪影（《愛麗絲夢遊仙境》為公共領域，不使用迪士尼版造型），依護照等級分為啟程、銀、金、晶鑽四種材質。

## 計分方式

1. **節奏**：Q1、Q2、Q3、Q7、Q11 加權加總，換算成精準／均衡／留白三個比例。
2. **取向**：Q5、Q9 加總，換算成經典／深度／放鬆三個比例。
3. **角色分數**＝節奏 × 取向，五個角色加總為 100%：
   - 白兔＝精準 ×（經典＋½ 放鬆）
   - 紅心皇后＝精準 ×（深度＋½ 放鬆）
   - 柴郡貓＝留白 ×（深度＋½ 放鬆）
   - 瘋帽匠＝留白 ×（經典＋½ 放鬆）
   - 愛麗絲＝均衡
4. 分數最高者為結果角色；同分時依愛麗絲、白兔、柴郡貓、紅心皇后、瘋帽匠的順序決定。
5. 推薦行程以角色對應的節奏配對，再依 Q6 主題、Q10 預算、Q12 避雷項目調整排序。

## 數據記錄

**目前關閉。** `index.html` 開頭的 `COLLECT = false` 是總開關：

| 狀態 | 行為 |
|---|---|
| `COLLECT = false`（目前） | 不記錄、不傳送任何事件；封面顯示「展示版，作答不會被記錄」；結果頁不出現回饋問卷與訪談邀請 |
| `COLLECT = true` | 每一步記錄為匿名事件（開場、開始、每題作答、完成、換角色、篩選、點地圖、點推薦、分享、回饋），並恢復回饋問卷與訪談邀請 |

要開始收集時：

1. 把 `COLLECT` 改成 `true`。
2. 部署在 GitHub Pages 時，在 `ENDPOINT` 填入 Google Apps Script 網址，事件會送到試算表；在 claude.ai 開啟時則寫入頁面內建資料庫。
3. 來源追蹤：網址加上 `?src=門市名稱` 或 `#src-門市名稱`，可區分 QR Code、社群等來源。
4. 統計頁：網址加上 `#stats`，可看完成率、推薦符合度、角色分布、各題作答分布與來源。

## App 版原型（旅客端）

網址：https://ky0126.github.io/FJUIEC/app/　給提報當天在場的學生與評審用手機操作。

| 分頁 | 內容 |
|---|---|
| 首頁 | 尚未測驗：測驗入口方框、熱門行程、探索地圖；測驗後：角色護照卡、點數、旅人檔案進度、為你推薦、比較／旅伴／地圖／顧問捷徑、通知鈴 |
| 探索 | 推薦清單（依旅人檔案自動套用「無購物站、避開炎熱、走路不累」等篩選，可勾 2–3 團比較）與歐洲地圖（點分類看這區的團） |
| 旅伴 | 邀請連結帶交接代碼；旅伴做完測驗自動配對，顯示合拍度、都在意的事、不一樣的地方與兩人都適合的 3 團，雙方各得 100 點。**一起決定**：選 2–3 團發起三選一投票（想去／可以／不行），旅伴點一下就好，系統算出推薦哪團、哪個月。**揪團**：任一團按「揪這團」選月份與目標人數（2–4 人），傳揪團小卡（自動附自我介紹揪人版），湊滿每人 +100 點，發起人把意願送給顧問確認名額（App 不收錢、不佔位；優惠數字待業師確認）。**我的團**：報名後的團友牆（原型用示範團） |
| 護照 | 數位護照、等級禮遇（啟程／銀／金／晶鑽）、點數明細、足跡地圖 |
| 會員 | 個人卡（角色頭像、暱稱、等級、生日月份、交接代碼）、點數／收藏／詢問三格、旅人檔案（一題一頁，完成跳「+100 點」）；右上齒輪進「設定」。還沒測驗時顯示「加入會員」：做完測驗自動成為啟程會員，不用填姓名電話 |

- 子頁：行程詳情、行程比較、找顧問（交接代碼＋QR＋摘要＋開 LINE）、通知中心（顧問、旅伴、優惠與禮遇）。
- 我的自我介紹：依測驗與旅人檔案自動產生，三種版本（一句話／標準／揪人版）、可增減標籤、換一句、自己改（60 字內，電話、LINE ID、網址會被擋下）；公開範圍預設只給領隊，可改全團或不公開。用在團友牆角色卡與揪團小卡。
- 團友牆（示範團）：出發倒數、集合資訊、領隊公告、全團角色組成（領隊用來安排自由時間）、團友角色卡；點對方標籤表示「我也是」，相同標籤配成小隊。沒有聊天室。
- 頭像：示範帳號在會員頁與首頁護照卡，照片與角色頭像每 4 秒翻面；護照頁大圖維持角色（看得到等級材質），右下角加小照片；結果頁、旅伴配對與團友牆只用角色頭像。
- 會員子頁：編輯個人資料（暱稱、角色頭像、生日月份、居住地區）、我的收藏、詢問紀錄（顧問更新狀態）、設定（帳號、通知分類與勿擾時段、預設篩選、重新測驗、下載我的資料、撤回同意、刪除全部資料、版本與意見回饋）、隱私權政策／服務條款／個資告知事項（課程原型草稿，正式版須永信法務審閱）。
- 導覽：每頁頂部列固定不捲走；子頁（行程、比較、通知、點數、找顧問）左上「← 上一頁」、右上「⌂ 回首頁」；分頁頁面從別頁點進來才出現「←」。從 QR 或連結直接打開深層頁面時，「上一頁」與手機返回鍵會回到上層頁面（例：行程 → 探索 → 首頁），不會直接跳出 App；回到清單時停在原本滑到的位置。
- 回到頂部：往下滑超過一個半畫面，右下浮出「↑」；再點一次目前的分頁或點頂部標題也會回到頂部。
- LINE 懸浮按鈕：首頁、探索、旅伴、護照、我的右下角有 LINE 綠色圓鈕，可「帶著我的資料問顧問」（附交接代碼與收藏的團）或「只是想先問問」；往下滑時自動讓開，不擋清單。測驗、結果、檔案題目、行程、比較、找顧問頁不放（這些頁已有詢問按鈕）。官方帳號 ID 目前用課程示範帳號，待業師提供永信的 ID。
- 測驗中按 ✕ 會先確認，答案保留，首頁測驗方框會變成「繼續測驗（第 N 題）」；結果頁右上有回首頁。
- 啟動頁有三種進入方式：同意並開始（存到 Supabase）、不儲存先試玩（只存在手機）、「我已經是永信旅客」→ 示範帳號 **林雅婷**（已測驗、填 2 張檔案、有旅伴怡君、1 筆詢問，生日月份留白可現場示範填寫領點；只存在手機）。
- 轉場動畫：①開場畫面（每支手機第一次打開播放約 3.5 秒：歐洲地圖淡淡浮出 → 辰宇落雁體寫出「一分鐘找到自己的歐洲」→ 橘色麥克筆底線 → 永信 Logo 沿筆順寫出；點一下跳過，「設定 → 關於」可重播；`app/splash.js`）②測驗結果揭曉（約 1.5 秒：地圖推近到第一站並點亮 → 角色卡翻面 → 分數條長出）③行程卡展開（首頁卡片封面放大成行程頁封面，用瀏覽器的 View Transitions，不支援時退回滑入）。手機開「減少動態效果」時全部關閉。
- 字型授權：標語 10 個字取自辰宇落雁體（SIL Open Font License 1.1，© 2022 Wang Li-Yu & Liu Wei-Chen），轉成向量圖形使用，未嵌入字型檔。
- 品牌色：主橘 #F39500、文字橘 #B85C00、深藍 #00223D、米白底 #F9F6EF；主要按鈕有立體邊與按壓動畫，手機開「減少動態效果」時關閉動畫。
- 價格標「示意」的行程（法瑞、馬爾他）官網沒有公開價格，待業師確認。
- 簡報只有 p.3 放 QR 與可點擊的網址 [ky0126.github.io/FJUIEC/find-my-europe](https://ky0126.github.io/FJUIEC/find-my-europe)（取自標語「一分鐘找到自己的歐洲」）：轉到 App 首頁並記來源 `src=deck`。轉址頁是根目錄的 `find-my-europe.html` 與 `find-my-europe/index.html`（網址結尾有沒有斜線都能開）。

## 檔案結構

| 檔案 | 說明 |
|---|---|
| `index.html` | 單一檔案的完整原型（畫面、插畫、地圖資料、計分與記錄邏輯都在裡面） |

| `icons/` | 主畫面圖示（192、512、Apple 180） |
| `.nojekyll` | 讓 GitHub Pages 直接提供靜態檔案 |
| `README.md` | 本說明 |
| `app/` | App 版原型（旅客端）：`index.html` 外框、`app.js` 畫面與路由、`app.css` 品牌樣式；`core.js`、`base.css` 由 `build_core.py` 從根目錄 `index.html` 抽出，行程與題目只改根目錄那份 ；改完 `app.js`／`app.css` 也要跑一次 `python3 app/build_core.py`，會更新 `index.html` 的 `?v=` 版本戳，手機才不會讀到舊檔 |
| `supabase/` | 資料庫結構：`schema.sql`、`schema_v2.sql`（旅伴、通知、點數明細）、`schema_v3.sql`（會員頭像、地區、偏好、撤回同意；旅客不能自改出團次數與分群）、`schema_v4.sql`（投票、揪團、自我介紹）、`seed.sql`（30 位示意客人），設定步驟見 `supabase/README.md` |
| `proposal/` | 提案的原始檔：列印版產生器、圖檔與 LINE 素材腳本、最新 PDF 與 LINE 上架包，說明見 `proposal/README.md` |

不需要建置或安裝套件。修改 `index.html` 後推上 `main` 分支，GitHub Pages 會在幾分鐘內更新。
