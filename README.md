# FJUIEC｜輔大《創新創業社》

## 歐洲旅人護照｜旅行風格測驗（課程原型）

輔大創新創業社「永信旅遊」課程專案的可操作原型：12 題情境測驗，依「節奏 × 取向」分出五種旅人角色（白兔／紅心皇后／柴郡貓／瘋帽匠／愛麗絲），並提供示意推薦行程、歐洲探索地圖與旅人護照足跡頁。

- 線上體驗：https://ky0126.github.io/FJUIEC/
- **目前為展示版，不收集任何作答數據**；不需登入。推薦行程皆為課程示意，價格參考永信官網同區域公開標價（2026/10/17 查詢）。
- 本頁不是任何旅行社的官方網站。

## 使用流程

1. **開場動畫**：白兔跑過、掉進兔子洞、抵達歐洲（可略過，同一次瀏覽只播一次）。
2. **封面**：五種旅人角色預覽，12 題、約 1 分鐘。
3. **12 題測驗**：每題上方一張情境插畫，點選答案自動進下一題；Q12 可複選。
4. **結果頁**：
   - 角色卡：五種角色分數全保留，可「換個角色」、可分享、可隱藏頭像。
   - 推薦行程：依節奏、主題、預算與避雷項目排序，並寫出推薦原因。
   - 篩選條件：自由時間多、連泊不換飯店、同節奏的人同團、10 天內、預算以內、少拉車等。
   - 歐洲探索地圖：真實國界，對應永信官網 23 個歐洲分類。
5. **旅人護照足跡頁**：以示意資料呈現出團後的足跡地圖與護照等級。
6. **回饋**（收集數據時才顯示）：推薦符合度（1–5 分）、5 題補充問卷、選填訪談邀請。

## 五種旅人角色

| 角色 | 代表 | 節奏 | 取向 |
|---|---|---|---|
| 經典收藏家 | 白兔 | 精準 | 經典名景 |
| 嚴選鑑賞家 | 紅心皇后 | 精準 | 深度體驗 |
| 慢遊生活家 | 柴郡貓 | 留白 | 深度體驗 |
| 隨興巡禮者 | 瘋帽匠 | 留白 | 經典名景 |
| 從容探索家 | 愛麗絲 | 均衡 | 不分取向 |

頭像為原創維多利亞剪影（《愛麗絲夢遊仙境》為公共領域，不使用迪士尼版造型），依護照等級分為啟程、銀、金、晶鑽四種材質。

## 計分方式

1. **節奏**：Q1、Q2、Q3、Q7、Q11 加權加總，換算成精準／均衡／留白三個比例。
2. **取向**：Q5、Q9 加總，換算成經典／深度／放鬆三個比例。
3. **角色分數**＝節奏 × 取向，五個角色加總為 100%：
   - 白兔＝精準 ×（經典＋½ 放鬆）
   - 紅心皇后＝精準 ×（深度＋½ 放鬆）
   - 柴郡貓＝留白 ×（深度＋½ 放鬆）
   - 瘋帽匠＝留白 ×（經典＋½ 放鬆）
   - 愛麗絲＝均衡
4. 分數最高者為結果角色；同分時依愛麗絲、白兔、柴郡貓、紅心皇后、瘋帽匠的順序決定。
5. 推薦行程以角色對應的節奏配對，再依 Q6 主題、Q10 預算、Q12 避雷項目調整排序。

## 數據記錄

**目前關閉。** `index.html` 開頭的 `COLLECT = false` 是總開關：

| 狀態 | 行為 |
|---|---|
| `COLLECT = false`（目前） | 不記錄、不傳送任何事件；封面顯示「展示版，作答不會被記錄」；結果頁不出現回饋問卷與訪談邀請 |
| `COLLECT = true` | 每一步記錄為匿名事件（開場、開始、每題作答、完成、換角色、篩選、點地圖、點推薦、分享、回饋），並恢復回饋問卷與訪談邀請 |

要開始收集時：

1. 把 `COLLECT` 改成 `true`。
2. 部署在 GitHub Pages 時，在 `ENDPOINT` 填入 Google Apps Script 網址，事件會送到試算表；在 claude.ai 開啟時則寫入頁面內建資料庫。
3. 來源追蹤：網址加上 `?src=門市名稱` 或 `#src-門市名稱`，可區分 QR Code、社群等來源。
4. 統計頁：網址加上 `#stats`，可看完成率、推薦符合度、角色分布、各題作答分布與來源。
