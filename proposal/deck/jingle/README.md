# 永信旅遊 品牌 Jingle（4.6 秒）

歌詞：一分鐘找到自己的歐洲，永信・旅遊！
記憶點：「洲」和「遊」押 -ou 韻、停在同一個音（高音 do）；「永信」「旅遊」兩拍一組，唱到「遊」全體同時收音。

## 檔案
| 檔案 | 用途 |
|---|---|
| jingle_完整版.wav | AI 合成男聲＋伴奏＋寫字聲（簡報第 1 張影片用這版） |
| jingle_伴奏.wav | 只有伴奏和寫字聲；之後換真人聲時用它混音 |
| strokes.json | 標語 81 筆的筆順與時間，影片遮罩和寫字聲共用，所以每一筆的聲音都對到那一筆 |
| build_video_html.py | 依筆順與每字時間產生影片頁面 |
| synth.py | 合成手風琴、低音、收音重拍、寫字聲並混音（numpy，無外部取樣） |
| vox/ | tts_m.py 用離線語音模型（sherpa-onnx Kokoro，男聲 zm_yunjian）逐字唸；sing2.py 用 WORLD 聲碼器改成旋律的音高和長度、保留 40% 聲調起伏，「永信旅遊」疊兩軌；asr.py 用語音辨識檢查 |

人聲是合成的示意歌聲。現成的離線男聲模型都是大陸口音，台灣口音要等真人錄。

筆順資料：hanzi-writer-data（Make Me a Hanzi，Arphic Public License），只用筆畫中線當遮罩，字形仍是辰宇落雁體。

## 配樂
- 0–0.2 秒：手風琴拉風箱；第一個字的寫字聲最大聲
- 0.2–2.6 秒：手風琴「蹦恰」波卡；寫字聲壓低 12 dB，照筆順每一筆一聲，下筆有輕輕的「嗒」
- 2.6–3.4 秒：手風琴跟著「永信」「旅遊」打重音
- 3.4–3.8 秒：全體重拍，3.8 秒一起收，只留很短的空間尾音；畫面在安靜中淡入封面
- 底線和 Logo 沒有寫字聲；響度 −14 LUFS
