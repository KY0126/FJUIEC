## 一句話輪廓

28 歲台北行銷企劃，和大學閨蜜同行，家裡有一隻英短貓「抹茶」。上班有效率、下班只想被安排；慢熟、怕熱、懶得排行程。喜歡抹茶、甜點、精品咖啡和香氛，旅行是她找靈感和充電的方式。第一趟想在 1–3 月去芬蘭看極光，下一趟想去巴黎買 Cartier 手環。她要的不是便宜，而是「很像我、不用動腦、照片好看，而且值得離開抹茶這幾天」。

## C. 生活方式

### C1 作息

| 時段 | 平日 | 假日 |
|---|---|---|
| 早上 | 7:30 起床，賴床滑 IG，化妝、餵抹茶 | 10:30 睡到自然醒 |
| 通勤、中午 | 捷運滑小紅書；午休去咖啡廳 | 和閨蜜吃早午餐 |
| 下午 | 提案、寫企劃，常加班 | 逛展覽、選物店、百貨精品，吃下午茶 |
| 晚上 | 19:00 下班，熱天通勤最煩躁；外送晚餐、陪貓 | 回家修圖、發 IG |
| 睡前 | 21:00–24:00 追劇、滑社群、問 ChatGPT（做旅遊決定的時段） | 在家追劇陪貓 |
| 其他 | — | 一個月一次「耍廢日」；夏天只去有冷氣的地方 |

### C2 興趣
- 逛展覽、設計選物店
- 香氛與保養
- 追劇、看電影
- 拍照、修圖
- 手帳、紀錄生活

### C3 音樂
- 會聽古典音樂，但只聽「輕古典」：上班專注、睡前放鬆時放 Spotify 的鋼琴與輕古典歌單（德布西、蕭邦、久石讓）
- 平常也聽 BLACKPINK、Lo-fi
- 很少進音樂廳；若是好拍又有氛圍的體驗（巴黎加尼葉歌劇院、維也納金色大廳一小時音樂會）就願意去

### C4 運動
- 一週 1–2 次瑜珈或皮拉提斯團體課，不做重訓
- 不吃蛋白粉；偶爾買蛋白飲或優格
- 不慢跑，出國也不跑；出國的「運動」是逛街走路、飯店 Spa、北歐桑拿

### C5 飲食
- 茶與甜點：抹茶、小甜點（馬卡龍、可頌、肉桂捲）
- 咖啡：網紅咖啡廳、精品咖啡、燕麥拿鐵
- 正餐：喜歡慢慢吃早午餐；不愛團體圓桌菜
- 酒：偶爾喝氣泡酒、香檳
- 地雷：不吃內臟、羊肉，不吃太獵奇的食物

### C6 偶像與影視
- 偶像：BLACKPINK 的 Jisoo（Dior 代言人）
- 角色：嚕嚕米、米飛兔、小王子
- 電影、影集：《艾蜜莉在巴黎》《愛在黎明破曉時》《冰雪奇緣》《午夜巴黎》

### C7 節日、禮物與驚喜
- 節日：會過生日、聖誕節、跨年；情人節和閨蜜過；傳統節日不太過
- 禮物：喜歡收禮，但要好拍、實用、有質感（香氛小樣、甜點禮盒、限量周邊）；不喜歡印大 logo 的贈品
- 驚喜：喜歡私下、個人化的小驚喜（飯店房間的生日卡片和小蛋糕）；不喜歡被當眾慶祝（全團唱生日快樂歌）

## F. 旅行觀與旅行行為

### F1 想法與痛點
- 想法：「告訴我幾個適合我的就好，不要給我一大堆資料。」
- 痛點：趕行程很累、懶得排行程、討厭業務丟網頁連結、討厭人擠人的景點
- 最怕：花了很多錢，結果又累又熱又擠，照片不好看
- 成功標準：「這趟很像我，而且我不用自己排。」

### F2 旅行需求
- 第一趟：1–3 月去芬蘭看極光，加上嚕嚕米、Marimekko、北歐咖啡，冬天也不熱
- 第二趟：巴黎，加上 Cartier 手環、Dior、甜點、《艾蜜莉在巴黎》取景地
- 時間：不確定要哪一週；避開 7–8 月；天數 9–10 天
- 交通：要有司機接應；長距離改搭火車或國內線班機
- 住宿：市中心、安靜、有冷氣，方便中途回去換裝
- 網路：每天和貓的保母視訊、發限動，需要 eSIM

### F3 旅行行為

| 項目 | 能接受 | 不能接受 |
|---|---|---|
| 戶外或室內 | 早上、傍晚在戶外；極光值得熬夜 | 中午在大太陽下 |
| 走路 | 城市散步、逛街，每天 1–2 萬步 | 爬山、健行、長時間排隊 |
| 坐車 | 火車、國內線班機 | 遊覽車單趟超過 3 小時 |
| 購物 | 自己選的精品、選物店、藥妝、市集 | 旅行社安排的購物站 |
| 運動 | 飯店 Spa、北歐桑拿、早上散步 | 慢跑、單車、運動型行程 |
| 領隊 | 需要時找得到人、推薦甜點店、幫忙拍照 | 被點名、團體自我介紹 |
| 嚐鮮 | 有人背書、附照片和理由的小眾店 | 自己冒險、太獵奇的食物 |
| 安全 | 購物後司機送回飯店 | 拿著戰利品搭地鐵 |

### F4 出國作息

| 時間 | 節奏 |
|---|---|
| 08:00–09:00 | 慢慢吃飯店早餐、保養化妝，9 點後才出發 |
| 09:00–11:30 | 戶外拍照、散步 |
| 11:30–17:00 | 室內：早午餐、美術館、購物 |
| 17:00–18:00 | 回飯店換裝、和貓視訊 |
| 18:00–20:00 | 傍晚拍照、自由用餐 |
| 20:00 以後 | 修圖、發限動；極光夜熬到凌晨 1 點，隔天要排輕鬆 |

## G. 決策旅程

| 階段 | 她會怎麼做 | 旅行社的機會 |
|---|---|---|
| 觸發 | 通勤時看到極光貼文 | IG、小紅書內容露出 |
| 搜尋 | 睡前問 ChatGPT、搜小紅書 | 測驗入口能被搜到、被分享 |
| 比較 | 不想比較 | 測驗加三張推薦卡 |
| 討論 | 晚上傳給閨蜜 | 推薦卡一鍵分享，閨蜜也能做測驗 |
| 卡關 | 怕選錯、怕被推銷 | 推薦原因、建議月份；LINE 文字接手 |
| 決定 | 閨蜜說好，能分期就訂 | 向業師確認永信是否提供分期 |
| 分享 | 回國後發 IG 標記 | 角色卡、數位旅人護照方便分享 |
| 回購 | 下次去巴黎 | 數位旅人護照記住偏好，分眾推薦 |
